# Advanced GitHub Demo

A small research-style project used in the **Advanced GitHub** workshop.
It trains a random forest classifier on the built-in Iris dataset and saves
the trained model and a confusion-matrix plot.

## Files

| File | Purpose |
| --- | --- |
| `sklearn_train.py` | Training script |
| `params.yaml` | Model settings used in the conflict exercises |
| `requirements.txt` | Python packages needed to run the script |

## Setup

```bash
python -m pip install -r requirements.txt
```
